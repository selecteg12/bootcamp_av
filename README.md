# Поиск объявлений услуг Avito

Решение для ранжирования объявлений услуг по поисковым запросам. Репозиторий содержит воспроизводимый исходный пакет и готовый answer.csv.

## Файлы

Скачайте [submission.zip](./submission.zip) и распакуйте архив. В нём лежат run.py, каталог src/, requirements.txt, подробный README решения и проверенный answer.csv. Parquet-данные и кэш в репозиторий не включены. Для запуска положите рядом с run.py исходные train.parquet, benchmark_queries.parquet и benchmark_items.parquet.

## Подход

Кандидаты собираются из истории точного запроса, похожих запросов (word/character TF-IDF), BM25 и character TF-IDF по каталогу объявлений. После объединения до 500 кандидатов LightGBM LambdaRank сортирует их; в ответ записываются до 50 item_id. Используются текстовые совпадения, retrieval score/rank, категория, локация, параметры и доступные характеристики объявлений.

Обучение использует положительные пары train, присутствующие в каталоге, и воспроизводимые hard negatives. Двухфолдовый pair-disjoint cross-fitting исключает целевую пару из retrieval-истории соответствующего фолда. Benchmark-разметка не читается.

## Проверка качества

| Validation | Candidate Recall@500 | Финальный Recall@50 |
|---|---:|---:|
| Запросы отсутствуют в fit | 0.7879 | 0.5768 |
| Исторические запросы, пары разделены | 0.7877 | 0.5902 |

Платформа сообщила Recall@50 **0.602930** для отправленного файла. В ошибках встречались опечатки, словоформы и синонимы, из-за которых запрос и заголовок не имели общих токенов. Подробности и ограничения описаны в README внутри архива.

## Запуск

Нужен Python 3.12. Выполните в распакованном каталоге:

```powershell
pip install -r requirements.txt
python run.py
```

Скрипт формирует и проверяет answer.csv. Seed фиксирован (42); версии библиотек закреплены. Идентификаторы обрабатываются строками.

Зависимости и их версии перечислены в requirements.txt. Используются scikit-learn, собственная sparse-реализация BM25 и LightGBM; предобученные модели и внешние API не требуются.
